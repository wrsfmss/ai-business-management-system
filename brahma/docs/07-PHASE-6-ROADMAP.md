# Phase 6 Roadmap

Phase 6 adds capabilities without changing the Phase 5 durable execution core.

## Wave 1

- GitHub read/issues/pull requests/actions
- documents search/read
- web research and source verification
- calendar read/create/update
- email read/search/draft

## Wave 2

- approved email send
- scheduled missions
- business monitoring
- reporting and notifications

## Wave 3

- advanced research
- CRM/business integrations
- financial workflows with appropriate approval policy
- specialist councils

Every capability follows:

```text
Discover -> Validate -> Register -> Policy -> Test -> Enable
```

No capability is permitted to bypass the Phase 5 pipeline:

```text
Policy -> Capability -> Execution -> Verification -> Reconciliation -> Audit
```
